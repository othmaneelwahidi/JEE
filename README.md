# JEE - Architecture et systemes distribues

Ce depot regroupe les activites pratiques du module Architecture JEE et
Systemes Distribues : injection de dependances, JPA, Spring Boot, Angular et
securite d'une application bancaire.

## Auteur

- Othmane El Wahidi El Alaoui
- othmane.elwahidi.elalaoui89@gmail.com

## Contenu

| Partie | Sujet | Technologies |
| --- | --- | --- |
| Activite 1 | Injection de dependances et mini-framework IoC | Java, Spring, XML, reflection |
| Activite 2 | Mapping objet-relationnel | Spring Boot, JPA, Hibernate, H2, MySQL |
| Activite 3 | Application Web MVC securisee | Spring MVC, Thymeleaf, Spring Security |
| Activite 4 | Gestion full-stack de produits | Angular 19, Spring Boot, REST, Bootstrap |
| Projet bancaire | Comptes et operations bancaires | Spring, Angular, JWT, Spring AI |

Chaque dossier contient un README avec ses objectifs, sa structure et ses
instructions d'execution.

## Prerequis

- JDK 17 et Maven
- Node.js, npm et Angular CLI 19 pour Angular
- Git

## Installation

```bash
git clone https://github.com/othmaneelwahidi/JEE.git
cd JEE
```

Les applications Maven se lancent depuis leur dossier avec
`mvn spring-boot:run`. Un frontend Angular se lance avec `npm install`, puis
`npm start`.

## Progression

1. Couplage faible et inversion de controle.
2. Persistance avec JPA et Spring Data.
3. MVC, authentification et autorisations.
4. Frontend Angular et backend REST.
5. Application bancaire securisee.
